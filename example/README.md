# YM FlutterToast example

This app demonstrates both APIs exposed by [YM FlutterToast](../):

- Platform toasts with `Fluttertoast.showToast` on Android, iOS, and web.
- Queued, fully-customizable Flutter overlay toasts with `FToast`.

## Run

From the package root:

```bash
cd example
flutter pub get
flutter run
```

The example follows the package requirements: Flutter 3.47.0+, Dart 3.13.0+, Android API 24+, and iOS 15+.
