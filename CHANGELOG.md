## 1.0.0

- Raised the minimum supported Flutter version to 3.47.0 and Dart version to 3.13.0.
- Updated the Android library toolchain to compile and target Android API 36 with Java 17.
- Raised the iOS deployment target to iOS 15.0 for current Flutter tooling.
- Reworked web Toastify integration to avoid JavaScript string interpolation and support cancellation.
- Improved overlay lifecycle safety, mounted-context handling, typed arguments, and color encoding.
- Added package analysis and automated widget tests.
